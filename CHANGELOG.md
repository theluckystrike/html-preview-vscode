# Changelog

## 0.1.0

- First release: live HTML preview beside the editor, with linked CSS (`@import`, `url()`), scripts, images, `srcset`, fonts, media and local iframes; no web server and no network.
- Updates as you type and when a linked file is saved, keeping the scroll position.
- Width presets (320 to 1440 px and custom), zoom, Back and Forward for local links, link confirm for web links, copy, console panel, scroll sync, JS on or off, Open in browser.
- Web resources load only after "Load for this file" or the setting `htmlPreview.loadRemoteResources`.
- Pages with endless loops are stopped; pages that try to leave stay on the file. Large files show a message first.
- Rating ask, Sponsor and More free viewers links, walkthrough.
