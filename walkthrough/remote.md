# Web resources and the console

HTML Preview loads nothing from the web on its own. When a page links CSS, fonts, scripts or images from a CDN, a bar says how many and from which hosts.

- "Load for this file" loads them for this page.
- "Always load" turns on the setting `htmlPreview.loadRemoteResources`.

The "Console" button shows `console.log` output, script errors, and files the page links that were not found.
